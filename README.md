## Featured project

### Absa Bank Kenya PLC — 3-Statement Financial Model
An integrated financial model and investment memo for Absa Bank Kenya PLC, built from five years of historical audited reports.

- Forecasts a five-year horizon (2026–2030)
- Uses loan growth, cost-to-income, and cost of risk as key drivers
- Links retained earnings across the income statement and balance sheet
- Includes a balance-sheet integrity check across the forecast period
